# AI 機能の準備手順

AI 機能（Claude）を使うための準備です。作業は 1 回だけで、30 分ほどかかります。

AI 機能は、Supabase の Edge Function「ai」を経由して Claude を呼び出します。Claude の API キーはサーバー（Supabase）の中だけに置き、アプリやリポジトリには入れません。

## 前提

- [クラウド同期の準備手順](supabase-setup.md) の 1〜5 が終わっていること（AI 機能はログインが必要です）。
- `supabase/schema.sql` を、AI の利用回数のテーブルを含む最新の内容で実行してあること。以前に実行した場合も、最新の内容をもう一度実行すれば追加されます。

## 費用の目安

- 既定のモデルは **Claude Opus 5.5**（入力 100 万トークンあたり 4 ドル、出力 100 万トークンあたり 20 ドル。2026 年 11 月時点）です。
- タスク 1 件を文章から作る程度の処理なら、1 回あたり数円の見込みです。
- 1 日あたりの回数に上限（既定 100 回）を設けています。
- **Anthropic 側で月の利用額の上限を設定してください**（下の手順 1）。上限に達すると AI 機能は止まり、それ以上は請求されません。

より安いモデルに切り替えることもできます（手順 3 の `AI_MODEL`）。

## 1. Claude の API キーを作る

1. Claude の開発者向け管理画面（https://platform.claude.com/ ）でアカウントを作成し、支払い方法を登録します。
2. **Settings → Limits** で、月の利用額の上限（Spend limit）を設定します。例: 5 ドル。
3. **API Keys** で新しいキーを作成し、表示された値（`sk-ant-` で始まる）をコピーします。

**このキーは、チャット・GitHub・アプリの設定ファイル（`.env.local` など）には絶対に貼り付けないでください。** 貼り付ける場所は次の手順 3 だけです。

## 2. 新規登録を止める（自分だけが使うため）

自分のアカウントを作成済みであることを確認してから、Supabase の管理画面で設定します。

1. **Authentication → Sign In / Providers** を開きます。
2. **Allow new users to sign up** をオフにして保存します。

これで、あなた以外はアカウントを作れなくなり、AI 機能も使えなくなります。

## 3. サーバーに秘密の値を設定する

Supabase の管理画面の **Edge Functions → Secrets** で、次を追加して **Save** します。

| Key | Value | 必須 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 手順 1 でコピーしたキー | 必須 |
| `AI_ALLOWED_EMAILS` | 自分のメールアドレス（複数ならカンマ区切り） | 推奨 |
| `AI_DAILY_LIMIT` | 1 日あたりの上限回数（未設定なら 100）。「AI で読み取る」「提案してもらう」と接続テストが 1 回ずつ数えられます | 任意 |
| `AI_MODEL` | 使うモデル（未設定なら `claude-opus-5-5`）。安くしたい場合は `claude-haiku-5-5` など | 任意 |

秘密の値は、設定した直後から関数に反映されます（関数の作り直しは不要です）。

## 4. 関数「ai」を公開する

次のどちらかで公開します。

### A. 管理画面から（かんたん）

1. **Edge Functions → Deploy a new function → Via Editor** を開きます。
2. 関数の名前を **`ai`** にします。
3. エディタの中身をすべて消し、このリポジトリの [`supabase/functions/ai/index.ts`](../supabase/functions/ai/index.ts) の内容を貼り付けます。
4. **Deploy function** を押します。

関数を更新するときは、同じ画面で中身を貼り替えて **Deploy updates** を押します。

### B. コマンドから

リポジトリのフォルダで実行します。プロジェクト ID は、Project URL の `https://` と `.supabase.co` の間の文字列です。

```bash
npx supabase login
```

```bash
npx supabase functions deploy ai --project-ref <プロジェクトID>
```

## 5. 動作を確認する

1. Web 版（または Expo Go）を開き、設定タブでログインします。
2. **AI 機能** の **AI の接続テスト** を押します。
3. 「AI と接続できました（モデル: …）」と出れば完了です。
4. ホーム画面の **AI で追加** を開き、「明日までに牛乳を買う、ランチ 980円」のように入力して **AI で読み取る** を押すと、タスクと家計簿の下書きが表示されます。
5. ホーム画面の **AI に今日やることを提案してもらう** を開き、**提案してもらう** を押すと、期限のないタスクなどから今日やるとよいものが提案されます。

## うまくいかないとき

| 表示 | 確認すること |
|---|---|
| AI 機能の準備が終わっていません | 手順 3 の `ANTHROPIC_API_KEY` が設定されているか。キーが有効か。Anthropic の利用額の上限に達していないか |
| このアカウントでは AI 機能を使えません | `AI_ALLOWED_EMAILS` に、ログインしているメールアドレスが入っているか |
| AI の処理に失敗しました | 手順 4 の関数名が `ai` になっているか。`supabase/schema.sql` を最新の内容で実行したか。Supabase の **Edge Functions → ai → Logs** |
| 今日の AI の利用回数の上限に達しました | 日本時間の 0 時に戻ります。`AI_DAILY_LIMIT` で上限を変えられます |
